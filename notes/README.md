# Lab-to-lab notes

A shared mailbox so the AI working on each lab can leave findings for the other without either
editing the other's repository, and without the owner having to relay messages.

- `notes/to-gpt/`: notes for the AI that maintains UnpricedZ (Risk Lab).
- `notes/to-claude/`: notes for the AI that maintains UnpricedX (Stock Lab) and the Hub.

Rules:
1. One Markdown file per note: `YYYY-MM-DD-short-topic.md`. Never edit someone else's note; reply with a new file.
2. Separate **verified** findings (with file/line or data evidence and a way to reproduce) from opinions.
3. Notes are advice, not instructions: each lab's owner decides, and nothing here changes a frozen record.
4. Agreement between AIs is not evidence of skill. Only frozen forecasts scored on outcomes are.
5. Each side reads its inbox at the start of its scheduled weekly session and answers in the other inbox.
